== Goal

When a `then:` block contains a call to `thrown(ExceptionType)` or `notThrown()`, the preceding `when:` block is wrapped in a try-catch that captures the thrown exception into `specificationContext.thrownException`.

---

== Context and Motivation

=== Spock's Behaviour

Spock's `ConditionRewriter.visitMethodCallExpression()` detects `thrown()` / `notThrown()` in `then:` blocks. When found, `SpecRewriter.rewriteWhenBlockForExceptionCondition()` transforms the preceding `when:` block:

[source,groovy]
----
// Developer writes:
when:
service.doSomething()

then:
thrown(RuntimeException)

// Spock transforms when: into:
setThrownException(null)
try {
  // when statements (variable declarations hoisted before the try block)
  service.doSomething()
} catch (Throwable $spock_ex) {
  setThrownException($spock_ex)
}
----

The `thrown(RuntimeException)` call in `then:` is evaluated at runtime by Spock's `Specification.thrown()` which:
1. Reads `thrownException` from `SpecificationContext`.
2. Asserts it is an instance of the given type.
3. Returns it (for further assertions in `then:`).

`notThrown()` similarly asserts that `thrownException` is `null`.

Key aspects:
* Variable declarations inside `when:` are **hoisted** out of the try block to keep them in scope for `then:`.
* `setThrownException(null)` is inserted before the try to reset any previous exception.
* The catch parameter is `Throwable` (any exception).

=== Spockk's Current Behaviour

Spockk does not detect `thrown()` / `notThrown()` calls at compile time. The `when:` block is not rewritten. At runtime:
* If `when:` throws, the exception propagates and the feature fails immediately.
* `thrown()` from Spock's `Specification` will throw `WrongExceptionThrownError` (because no exception was stored).

== Planned Changes

=== 1. Detect exception condition calls during collection

In `ValidatingFeatureBlockCollector.kt` (or a new scan pass), detect whether a `then:` block contains a call to:
* `thrown(SomeType)` (member function of `Specification`)
* `notThrown()` (member function of `Specification`)

This can be done by scanning the `then:` block's IrStatements for `IrCall` nodes where the callee's name matches `"thrown"` or `"notThrown"` and the receiver is `this` (a `Specification` instance).

Store the result in `FeatureContext`:

[source,kotlin]
----
data class FeatureContext(
  // ... existing fields ...
  val thenBlocksWithExceptionCondition: Set<Int>  // indices of then: blocks that have thrown()/notThrown()
)
----

=== 2. Add `IrIdentifiers` constants

const val SET_THROWN_EXCEPTION = "setThrownException"

=== 3. Implement `when:` block rewriting in `FeatureRewriter`

When a `then:` block has an exception condition, rewrite the immediately preceding `when:` block:

[source,kotlin]
----
fun rewriteWhenBlockForExceptionCondition(
  whenBlock: FeatureBlockStatements,
  thisParam: IrValueParameter
): List<IrStatement> {
  // 1. Hoist variable declarations out of the try block
  val (varDecls, nonVarStats) = whenBlock.statements.partition { it.isVariableDeclaration() }

  // 2. Build the try-catch wrapper
  val tryBody = irBlock { nonVarStats.forEach { +it } }
  val catchParam = irCatchParameter("\$spock_ex", throwableType)
  val catchBody = irBlock {
    +irSetThrownException(thisParam, irGetValue(catchParam))
  }
  val tryCatch = irTryCatch(tryBody, catches = listOf(irCatch(catchParam, catchBody)))

  // 3. Return: setThrownException(null), var decls, try-catch
  return buildList {
    add(irSetThrownException(thisParam, irNull()))
    addAll(varDecls)
    add(tryCatch)
  }
}
----

=== 4. Wire detection into the transformation pipeline

In `FeatureRewriter.rewriteFeatureMethod()`:

[source,kotlin]
----
for ((index, block) in featureContext.featureBlocks.withIndex()) {
  val statements = when {
    block.label == FeatureBlockLabel.THEN &&
      (index / 2) in featureContext.thenBlocksWithExceptionCondition ->
        // Preceding when: block — check if already rewritten
        // (detection on then: triggers rewrite of corresponding when:)
        block.statements

    block.label == FeatureBlockLabel.WHEN &&
      featureContext.isWhenPrecedingExceptionThen(index) ->
        rewriteWhenBlockForExceptionCondition(block, thisParam)

    else -> block.statements
  }
  emitBlockStatements(statements, blockIndex)
}
----
