= TODO-3: Fix Cleanup Block to Include `$spock_failedBlock` / `setCurrentBlock()` Pattern
:toc:
:toc-title: Contents

*Parent*: link:specification.adoc[DR-02: Align Spockk IR Transformations with Spock AST Transformations] +
*Status*: Proposed

'''

== Goal

Update the cleanup block try-catch-finally structure to match Spock's full output:

1. `$spock_failedBlock` variable is declared inside `finally`.
2. When an exception was thrown by the feature, the current block is captured into `$spock_failedBlock` before cleanup starts.
3. `SpockRuntime.callBlockEntered/Exited` are emitted for the cleanup block inside the `finally`.
4. A nested `finally { setCurrentBlock($spock_failedBlock) }` restores the failed block's context after cleanup.

'''

== Context and Motivation

=== Spock's Full Cleanup Structure

From Spock's `SpecRewriter.visitCleanupBlock()` and the snapshot `cleanup_rewrite_keeps_correct_method_reference.groovy`:

[source,groovy]
----
Throwable $spock_feature_throwable
try {
    SpockRuntime.callBlockEntered(this, 0)  // setup/when/expect block(s)
    // ... block statements ...
    SpockRuntime.callBlockExited(this, 0)
    // ... additional blocks with callBlockEntered/Exited ...
} catch (Throwable $spock_tmp_throwable) {
    $spock_feature_throwable = $spock_tmp_throwable
    throw $spock_tmp_throwable
} finally {
    BlockInfo $spock_failedBlock = null
    try {
        if ($spock_feature_throwable != null) {
            $spock_failedBlock = this.getSpecificationContext().getCurrentBlock()
        }
        SpockRuntime.callBlockEntered(this, cleanupBlockIndex)
        // cleanup statements
        SpockRuntime.callBlockExited(this, cleanupBlockIndex)
    } catch (Throwable $spock_tmp_throwable) {
        if ($spock_feature_throwable != null) {
            $spock_feature_throwable.addSuppressed($spock_tmp_throwable)
        } else {
            throw $spock_tmp_throwable
        }
    } finally {
        if ($spock_feature_throwable != null) {
            ((SpecificationContext) this.getSpecificationContext())
                .setCurrentBlock($spock_failedBlock)
        }
    }
}
this.getSpecificationContext().getMockController().leaveScope()
----

=== Spockk's Current Cleanup Structure

From `CleanupBlockRewriter.kt`, the current output (from transformed snapshot `cleanup/CleanupBlock.kt`):

[source,kotlin]
----
var `$spock_feature_throwable`: Throwable? = null
try {
    // feature statements (NO callBlockEntered/Exited)
} catch (`$spock_tmp_throwable`: Throwable) {
    `$spock_feature_throwable` = `$spock_tmp_throwable`
    throw `$spock_tmp_throwable`
} finally {
    try {
        // cleanup statements (NO callBlockEntered/Exited)
    } catch (`$spock_tmp_throwable`: Throwable) {
        if (`$spock_feature_throwable` != null) {
            `$spock_feature_throwable`!!.addSuppressed(`$spock_tmp_throwable`)
        } else {
            throw `$spock_tmp_throwable`
        }
    }
}
// NO leaveScope()
----

Differences from Spock:

1. No `SpockRuntime.callBlockEntered/Exited` around any blocks (depends on TODO-2).
2. No `$spock_failedBlock` variable declaration.
3. No `if ($spock_feature_throwable != null) { $spock_failedBlock = getCurrentBlock() }` before cleanup.
4. No nested `finally { setCurrentBlock($spock_failedBlock) }` inside the cleanup's try-catch.
5. No `leaveScope()` after the outer try-catch-finally (depends on TODO-2).

'''

// Builds: this.getSpecificationContext().getCurrentBlock()

=== 3. Update `CleanupBlockRewriter.kt`

Rewrite the `rewrite()` method to produce the full structure:

[source,kotlin]
----
// Step 1: Declare $spock_feature_throwable at the top of the method
val featureThrowableVar = irVar("${'$'}spock_feature_throwable", nullableThrowableType)

// Step 2: Build the outer try body with block entry/exit calls around feature blocks
val featureStatements = buildFeatureStatementsWithBlockCalls(featureBlocks, thisParam)

// Step 3: Build the outer catch (capture and rethrow)
val outerCatch = buildCaptureCatch(featureThrowableVar)

// Step 4: Build $spock_failedBlock variable (declared inside finally)
val failedBlockVar = irVar("${'$'}spock_failedBlock", nullableBlockInfoType, initializer = irNull())

// Step 5: Build cleanup body with:
//   - if ($spock_feature_throwable != null) { $spock_failedBlock = getCurrentBlock() }
//   - callBlockEntered(cleanupBlockIndex)
//   - cleanup statements
//   - callBlockExited(cleanupBlockIndex)
val cleanupBody = buildCleanupBody(
  featureThrowableVar, failedBlockVar, cleanupStatements, cleanupBlockIndex, thisParam
)

// Step 6: Build inner catch (addSuppressed or rethrow)
val innerCatch = buildSuppressCatch(featureThrowableVar)

// Step 7: Build inner finally (setCurrentBlock if feature threw)
val innerFinally = buildRestoreBlockFinally(featureThrowableVar, failedBlockVar, thisParam)

// Step 8: Build the inner try-catch-finally (cleanup wrapper)
val cleanupTryCatch = IrTryCatchImpl(
  tryResult = cleanupBody,
  catches = listOf(innerCatch),
  finallyExpression = innerFinally
)

// Step 9: Build the outer finally containing $spock_failedBlock + cleanupTryCatch
val outerFinally = irBlock {
  +irVar(failedBlockVar)
  +cleanupTryCatch
}

// Step 10: Build the outer try-catch-finally
val outerTryCatch = IrTryCatchImpl(
  tryResult = featureStatements,
  catches = listOf(outerCatch),
  finallyExpression = outerFinally
)

// Add to function body: featureThrowableVar decl + outerTryCatch + leaveScope
----

=== 4. Pass block indices to `CleanupBlockRewriter`

The cleanup block's index in `@FeatureMetadata.blocks` must be passed to `CleanupBlockRewriter` so it can emit the correct `callBlockEntered(this, cleanupIndex)` call.

In `FeatureRewriter`, compute the cleanup block index as:

[source,kotlin]
----
val cleanupBlockIndex = featureContext.blocks
  .filter { it.label.blockKind != null }
  .indexOfFirst { it.label == FeatureBlockLabel.CLEANUP }
----
