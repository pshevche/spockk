= Plan: Insert Block Entry/Exit Notification Calls and `MockController.leaveScope()`
:toc:
:toc-title: Contents

== Overview

Add `SpockRuntime.callBlockEntered(this, blockIndex)` and `callBlockExited(this, blockIndex)` around each block's statements in feature methods, and append `MockController.leaveScope()` at the end of every feature method.
This enables Spock extensions to observe block transitions and ensures mock scopes are properly cleaned up.

This increment depends on plan 01 (correct block metadata) so that block indices match the `@FeatureMetadata.blocks` array order.

== Changes

=== `spockk-compiler-plugin/.../ir/IrIdentifiers.kt`

Add FQN constants for `SpockRuntime`, `SpecificationContext`, and `MockController`:

[source,kotlin]
----
val SPOCK_RUNTIME_FQN = RUNTIME_PKG_FQN.child("SpockRuntime")
val SPECIFICATION_CONTEXT_FQN = RUNTIME_PKG_FQN.child("SpecificationContext")
val MOCK_CONTROLLER_FQN = MOCK_PKG_FQN.child("runtime").child("MockController")
----

=== `spockk-compiler-plugin/.../transformer/FeatureRewriter.kt`

Add private helpers for building the IR calls:

* `irCallBlockEntered(builder, thisParam, blockIndex)` -- builds `SpockRuntime.callBlockEntered(this, N)`
* `irCallBlockExited(builder, thisParam, blockIndex)` -- builds `SpockRuntime.callBlockExited(this, N)`
* `irMockControllerLeaveScope(builder, feature, thisParam)` -- builds `this.getSpecificationContext().getMockController().leaveScope()`

Update `rewriteFeatureStatements()` to wrap each merged block with entry/exit calls and append `leaveScope()`:

[source,kotlin]
----
mergedBlocks.forEachIndexed { blockIndex, block ->
  result.add(irCallBlockEntered(builder, thisParam, blockIndex))
  result.addAll(block.statements)
  result.add(irCallBlockExited(builder, thisParam, blockIndex))
}
feature.mutableStatements()?.add(irMockControllerLeaveScope(builder, feature, thisParam))
----

For features with cleanup blocks, block entry/exit calls for non-cleanup blocks are emitted inside the try body; cleanup block calls are deferred to plan 03.
