== Overview

Add the full end-to-end and engine-level test suite for lifecycle methods. Some of these tests may be partially written in earlier increments (e.g., `FixtureMethodsSmokeTest` in increment 3); this increment ensures complete coverage matching Spock's own test suite.

== Changes

=== `spockk-specs/src/test/kotlin/.../smoke/FixtureMethodsSmokeTest.kt` (new file)

A Spockk spec that verifies basic fixture method execution order using a shared execution log:

* `setupSpec()` runs once before any feature
* `setup()` runs before each feature
* `cleanup()` runs after each feature
* `cleanupSpec()` runs once after all features
* `cleanup()` runs even when `setup()` fails
* `cleanup()` does NOT run when a field initializer fails (instance wasn't fully constructed)

=== `spockk-specs/src/test/kotlin/.../smoke/FixtureMethodsInheritanceSmokeTest.kt` (new file)

A Spockk spec verifying parent/child ordering across a spec hierarchy:

* Parent `setupSpec()` before child `setupSpec()` (top-down)
* Parent `setup()` before child `setup()` (top-down)
* Child `cleanup()` before parent `cleanup()` (bottom-up)
* Child `cleanupSpec()` before parent `cleanupSpec()` (bottom-up)

=== `spockk-specs/src/test/kotlin/.../smoke/CleanupBlockSmokeTest.kt` (new file)

A Spockk spec verifying cleanup block runtime behavior:

* Cleanup block runs when no exception is thrown
* Cleanup block runs when the feature throws
* Cleanup block can access all local variables declared before it

=== `spockk-specs/src/test/kotlin/.../smoke/CleanupBlockExceptionHandlingSmokeTest.kt` (new file)

A Spockk spec verifying exception suppression semantics:

* When feature throws and cleanup also throws: feature exception propagates, cleanup exception is added as suppressed
* When feature succeeds and cleanup throws: cleanup exception propagates normally

=== `spockk-specs/src/test/kotlin/.../runtime/FixtureMethodsEngineTest.kt` (new file)

Engine-level tests using `EngineTestKitUtils.execute()`:

* Spec with fixture methods: all features are discovered and executed
* `setupSpec()` failure causes all features to be aborted
* `setup()` failure for one iteration does not affect other iterations
