== Overview

Transform detected fixture methods: make them `private` (de-virtualization) and validate that `setupSpec()`/`cleanupSpec()` do not access instance fields. This is the change that makes the Spock runtime able to discover and invoke fixture methods correctly via reflection.

}

The `makePrivate()` transformation is essential: it de-virtualizes fixture methods so that the Spock runtime can invoke each class's fixture method independently via reflection, without Kotlin's virtual dispatch routing the call to the most-derived override.
