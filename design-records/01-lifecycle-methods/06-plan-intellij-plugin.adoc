== Overview

The IntelliJ plugin suppresses "unused expression" warnings for Spockk block label references by checking their fully qualified names against an allowlist. Without this change, using `setup:` or `cleanup:` in a feature method causes the IDE to flag the reference as an unused expression.

== Changes

=== `spockk-intellij-plugin/.../Psi.kt`

Add the new block label FQNs to `SPOCKK_BLOCKS_FQN`:

[source,kotlin]
----
private val SPOCKK_BLOCKS_FQN =
  setOf(
    // ... existing entries ...
    "io.github.pshevche.spockk.lang.setup",
    "io.github.pshevche.spockk.lang.cleanup"
  )
----
