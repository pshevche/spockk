= spockk-intellij-plugin

Provides support for Spockk tests in IntelliJ.
The built-in plugin for Spock tests does a lot of the heavy lifting:

- It detects specifications and features.
- It provides Gradle run configurations for those tests.

This plugin adds a single extension that ensures that Kotlin-specific syntax for feature blocks is not marked as unused by IntelliJ.

== Noteworthy components

- link:src/main/kotlin/io/github/pshevche/spockk/intellij/SpockkUnusedExpressionInspectionSuppressor.kt[SpockkUnusedExpressionInspectionSuppressor]: prevents Spockk-specific expressions from being marked as unused.
This applies to block labels without descriptions and data provider statements.
- link:src/main/kotlin/io/github/pshevche/spockk/intellij/SpockkDataTableFormattingModelBuilder.kt[SpockkDataTableFormattingModelBuilder]: enhances default Kotlin code formatter to pretty-format data tables.

== Dogfooding the development version

1. Run `./gradlew :spockk-intellij-plugin:build`.
2. Navigate to "IntelliJ IDEA -> Settings -> Plugins -> (Gear Icon) -> Install Plugin from Disk".
3. Navigate to `spockk-intellij-plugin/build/libs`.
4. Select `spockk-intellij-plugin-<version>.jar`.
5. Restart the IDE if prompted.
